DNS Worker 提供業界領先的**後量子零知識端到端加密 (Post-Quantum Zero-Knowledge E2EE)** 解析日誌儲存架構，確保即使使用者的雲端資料庫或物理磁碟被完全匯出，攻擊者在未來量子計算時代也絕對無法還原真實的歷史域名訪問記錄。

## 預設狀態與按需啟用

> [!NOTE]
> **預設處於停用狀態**：考慮到絕大多數使用者追求極致的輕量解析效能與跨裝置即時日誌可見性，系統**預設停用 E2EE**。在預設狀態下，DNS 查詢日誌以標準非加密格式持久化儲存，無需任何客戶端本地私鑰解鎖開銷。

### 如何啟用 E2EE（按需開啟）

如果您對 DNS 解析日誌有高強度的零知識隱私保障需求：

1. 前往 **「賬戶與安全」** -> **「端到端加密 (E2EE)」** 卡片；
2. 點選 **「使用 Passkey 生成加密金鑰並啟用」**（推薦，支援 Touch ID / Face ID / Windows Hello 一鍵生物識別解鎖）或 **「使用恢復金鑰生成」**；
3. 初始化成功後，系統將自動開始為後續產生的所有 DNS 日誌採用 NIST FIPS 203 **P256-MLKEM768** 加密落盤；
4. 您可隨時在卡片中通過主開關暫停/開啟加密，或在必要時徹底清除金鑰對。

## 核心設計原理

1. **零知識加密儲存**：
   - DNS Worker 服務端在收到解析日誌後，僅使用公鑰將其加密為不可逆密文；
   - 資料庫中不儲存任何可用於解密的私鑰。
2. **NIST FIPS 203 混合密碼學**：
   - 採用 **P256-MLKEM768** 混合格密碼體系（兼顧現代 ECC 經典橢圓曲線安全性與抵禦 Shor 演算法破解的後量子格密碼學能力）。
3. **小時級滾動 KEM DEK (Data Encryption Key)**：
   - 每小時自動派生並輪換新的資料加密金鑰，限制單金鑰的暴露視窗。
4. **硬體通行金鑰保護 (WebAuthn / Passkey)**：
   - 使用者在瀏覽器端通過指紋、Face ID 或安全鑰匙解密私鑰，解密計算完全在客戶端本地執行。
