DNS Worker 提供业界领先的**后量子零知识端到端加密 (Post-Quantum Zero-Knowledge E2EE)** 解析日志存储架构，确保即使用户的云端数据库或物理磁盘被完全导出，攻击者在未来量子计算时代也绝对无法还原真实的历史域名访问记录。

## 默认状态与按需启用

> [!NOTE]
> **默认处于停用状态**：考虑到绝大多数用户追求极致的轻量解析性能与跨设备即时日志可见性，系统**默认停用 E2EE**。在默认状态下，DNS 查询日志以标准非加密格式持久化存储，无需任何客户端本地私钥解锁开销。

### 如何启用 E2EE（按需开启）

如果您对 DNS 解析日志有高强度的零知识隐私保障需求：

1. 前往 **「账户与安全」** -> **「端到端加密 (E2EE)」** 卡片；
2. 点击 **「使用 Passkey 生成加密密钥并启用」**（推荐，支持 Touch ID / Face ID / Windows Hello 一键生物识别解锁）或 **「使用恢复密钥生成」**；
3. 初始化成功后，系统将自动开始为后续产生的所有 DNS 日志采用 NIST FIPS 203 **P256-MLKEM768** 加密落盘；
4. 您可随时在卡片中通过主开关暂停/开启加密，或在必要时彻底清除密钥对。

## 核心设计原理

1. **零知识加密存储**：
   - DNS Worker 服务端在收到解析日志后，仅使用公钥将其加密为不可逆密文；
   - 数据库中不保存任何可用于解密的私钥。
2. **NIST FIPS 203 混合密码学**：
   - 采用 **P256-MLKEM768** 混合格密码体系（兼顾现代 ECC 经典椭圆曲线安全性与抵御 Shor 算法破解的后量子格密码学能力）。
3. **小时级滚动 KEM DEK (Data Encryption Key)**：
   - 每小时自动派生并轮换新的数据加密密钥，限制单密钥的暴露窗口。
4. **硬件通行密钥保护 (WebAuthn / Passkey)**：
   - 用户在浏览器端通过指纹、Face ID 或安全钥匙解密私钥，解密计算完全在客户端本地执行。
