## 🛡️ 广告与恶意域名拦截

DNS Worker 从底层架构起即作为**保护性 DNS（Protective DNS）**设计，在网络最基础的解析层为所有设备提供全天候威胁防御与隐私屏障：

- **广告与全网遥测静默屏蔽**：无需在终端安装繁重的过滤插件，即可在路由器、手机、平板与电视盒子全局屏蔽横幅广告、视频贴片、诱导弹窗以及 Windows / Android 系统级诊断遥测。
- **主动威胁防御与反钓鱼**：实时拦截木马分发点、勒索病毒回调、钓鱼诈骗页面、挖矿脚本以及僵尸网络命令与控制（C2）恶意域名。
- **双层极速匹配引擎**：融合紧凑布隆过滤器（Bloom Filter 初筛）与前缀树（Trie 精确验证），毫秒级并发评估数十万条规则，兼顾极限性能与 0 误报。
- **灵活完备的规则体系**：开箱即用支持主流精选规则源（OISD Big、AdGuard Base、HaGeZi Multi PRO++、StevenBlack Hosts），并支持自定义精确/通配符/正则白名单与黑名单，以及局域网 DNS 重写映射。
- **实时审计与威胁日志**：直观展示放行（PASS）、阻断（BLOCK）与重写（REWRITE）状态，一键展开抽屉深入排查拦截规则归属、客户端来源及解析耗时。
